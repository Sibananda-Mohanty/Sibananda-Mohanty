06 / How I think

How I think about data work

The principles I bring to every platform, from the first requirement to the production handover.

01

Start from the consumer

Every pipeline exists for someone downstream. I clarify who uses the data, how fresh it must be and what 'correct' means before writing code.

02

Reliability before cleverness

Simple, observable jobs that fail loudly and recover cleanly beat clever ones nobody can debug at 3 a.m.

03

Prove it matches

In migrations, functional compatibility is the goal. I validate outputs against the source system before any cut-over.

04

Performance is a feature

Partitioning, pruning and query rewrites keep both latency and cloud cost under control as data grows.

05

Governance by default

Access, lineage and compliance are designed in from the start, not retrofitted after an audit.

06

Hand over, don't hand off

Clear documentation and runbooks so the team that inherits the platform can operate it with confidence.
